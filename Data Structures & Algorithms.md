# Algorithms Approaches

### Two Pointers
- Uses two indices to traverse arrays/strings, typically moving inward or in the same direction, to solve search or pair-sum problems in O(n) time

### Sliding Window
- Maintains a subset of data (a window) and moves it across arrays or strings to calculate subarray sums or substring frequencies in O(n) time
### Hashing / Frequency Maps 
- Uses a hash table to achieve O(1) lookups, reducing complex, nested loops to linear O(n) frequency mapping or finding duplicates.
### Fast & Slow Pointers (Hare & Tortoise)
- Uses two pointers moving at different speeds to detect cycles in linked lists or find the middle element in O(n) time
### Breadth-First Search (BFS)
- Traverses graphs or trees level-by-level, often used to find the shortest path in an unweighted graph in O(V+E) time
### Depth-First Search
- Explores paths to the maximum depth before backtracking, crucial for traversing tree or graph structures.
### Top K Elements / Heap
- Uses a min-heap or max-heap to efficiently manage the largest/smallest elements, often achieving O(n log k)
### Prefix Sum / Cumulative Sum
- Pre-calculates sums of subarrays to answer range-sum queries in O(1) after preprocessing O(n)
### Monotonic Stack/Queue
- Maintains a stack or queue in sorted order to find the next greater or smaller element in O(n) time
### Topological Sort (Kahn's Algorithm)
- Used for ordering nodes in a Directed Acyclic Graph (DAG) in O(V+E), common for scheduling tasks
